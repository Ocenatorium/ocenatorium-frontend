O PROJEKCIE

O projekcie

Ocenatorium Sejmowe pokazuje dane o posłach w przystępnej, wizualnej formie. Projekt pozwala porównywać kolejne kadencje oraz obserwować zmiany w zawodach, poziomie wykształcenia, wieku i doświadczeniu parlamentarzystów.

ŹRÓDŁA

Źródło danych

Dane pochodzą z publicznego API Sejmu Rzeczypospolitej Polskiej. Analizy mogą nie obejmować informacji, których posłowie nie podali w swoich profilach.
